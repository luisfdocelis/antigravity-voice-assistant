# Test Generator Skill

## Cuándo usar
Activar cuando se requiera crear o expandir la cobertura de pruebas de un módulo o funcionalidad.

## Reglas
1. Analizar el código objetivo e identificar flujos críticos y casos límite (edge cases).
2. Utilizar el framework de pruebas detectado en el stack del proyecto (ej. Jest, Pytest, Catch2, JUnit).
3. Asegurar el aislamiento mediante mocks o stubs para pruebas unitarias.
4. Estructurar siguiendo el patrón Arrange-Act-Assert (AAA).
